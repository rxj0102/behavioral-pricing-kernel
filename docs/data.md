# Data

Status: Phase 1. Only the synthetic source has been run. No real market data has been ingested, because the build sandbox network policy blocked every external host and no WRDS credentials exist. Nothing produced from synthetic data may be reported as an empirical result.

## Data decision

- WRDS (OptionMetrics): not available, no credentials. The adapter exists (availability check only) and reads WRDS_USERNAME from the environment. Credentials are never hardcoded, printed or logged.
- Owner decision: free sources only, no paid data.
- Real fallback: a daily snapshot of the free CBOE delayed SPX chain, collected going forward. The sample will be short and will not contain 2008 or 2020. This limits what H1 to H4 can support and the paper will say so. The parser is written but tested only on a hand-built fixture, see below.
- Synthetic Heston panel: used only for method validation (identification study, unit and integration tests).

## Option panel schema

Columns: date, dte (calendar days to expiry), strike, cp (C or P), bid, ask, open_interest, spot, rf (continuously compounded risk-free rate). Every source maps into this schema (src/bpk/data/schema.py).

## Synthetic Heston panel

Generated by src/bpk/data/synthetic.py with prices from the semi-closed-form Heston formula (src/bpk/data/heston.py, checked against adaptive quadrature to about 2e-9 and against the Black-Scholes limit). Option prices use risk-neutral dynamics. The latent state follows physical dynamics with an equity premium eta times variance and a faster-mean-reverting variance process (lam), so a variance risk premium exists. Quotes have a spread, a 0.05 tick, open interest that decays in moneyness, and injected defects: crossed quotes (0.2 percent) and missing asks (1 percent). Truth (spot, variance) is stored separately and is never given to the cleaner. Because the true Heston kernel is monotone in the return, this panel has no pricing kernel puzzle by construction.

## Cleaning

Implemented in src/bpk/data/clean.py, steps listed in its docstring. Each step is counted and written to results/tables/cleaning_stats__SOURCE.csv. Notes on reading the table:

- The parity_forward step also drops every quote without a partner of the other type at the same strike, because only strikes with both a call and a put enter parity. Most of its drops are such wing quotes, not parity violations.
- Forward accuracy on the synthetic panel is checked in tests (relative error below 1e-4) and was about 3e-6 on the fast config run.
- The itm_duplicate step keeps puts below the forward and calls at or above it.

## CBOE delayed chain (unverified)

src/bpk/data/cboe.py parses an assumed JSON layout. It has not been run against the live endpoint, and the endpoint is not a documented API, so the owner should check its terms of use. A person must inspect the first live snapshot before any result uses it. It can only return today, so it cannot backfill.

## Provenance

Every cached dataset is recorded in the manifest with source, series, date range, SHA-256 of the cached file, row count and retrieval date. A cached file whose hash differs from the manifest raises an error. Rebuilding with the same seed and config gives identical output (tested).
